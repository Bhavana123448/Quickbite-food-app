#  QuickBite – Food Delivery Web App

##  Description
QuickBite is a simple food delivery web application built using HTML, CSS, and JavaScript. It allows users to view food items, add them to a cart, and place orders.

##  Features
- Add food items to cart   
- Increase or decrease quantity 
- Remove items from cart 
- View total price 
- Search food items  
- Dark mode 
- Simple payment page   

##  Technologies Used
- HTML  
- CSS  
- JavaScript  
- localStorage (to store cart data)  

##  How It Works
1. Open the home page  
2. Add food items to cart  
3. Go to cart page  
4. Update quantity or remove items  
5. Click payment and place order
